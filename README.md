# 🌍 VentureAI - AI Travel Chatbot

VentureAI is an AI-powered travel assistant built using Streamlit and Google Gemini API.

---

## 🚀 Features
- AI travel recommendations
- Chat-based interface
- Local + Gemini AI responses
- Modern UI design

---

## 🛠️ Tech Stack
- Python
- Streamlit
- Google Gemini AI
- Scikit-learn

---
